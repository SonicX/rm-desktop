# Privacy Policy — RMConnect (Связь РМ)

**Last updated:** March 2026

## Overview

RMConnect is a desktop communication client. Your privacy is important to us.

## Data Collection

RMConnect **does not** collect, store, or transmit any user data to the developers or any third-party service.

Specifically, RMConnect does **not**:

- Collect usage analytics or telemetry
- Track user behavior or interactions
- Send crash reports automatically
- Contact any external service without explicit user action
- Include advertising or tracking SDKs

## Data Transmission

RMConnect connects **only** to the server URL configured by the user during setup. All communication (messages, voice/video calls, screen sharing) occurs exclusively between the user's device and their configured server.

No data is transmitted to:
- The RMConnect developers
- Цифровые технологии РМ (Digital Technologies RM)
- Any analytics, advertising, or third-party service

## Local Storage

RMConnect stores the following data locally on the user's device:

- User preferences and application settings
- Server connection configuration (URL, credentials)
- Application logs (stored locally, not transmitted)

This data remains on the user's device and is not accessible to anyone else.

## Third-Party Components

RMConnect uses the following third-party open source components that may interact with external services **only as configured by the user**:

- **Jitsi** — for voice/video conferencing (connects to the Jitsi server specified by the user's configured server)
- **Electron** — application framework (does not transmit data independently)

## System Permissions

RMConnect may request the following system permissions:

- **Microphone** — for voice calls (only when initiated by the user)
- **Camera** — for video calls (only when initiated by the user)
- **Screen capture** — for screen sharing (only when initiated by the user)
- **Notifications** — for desktop message notifications
- **Audio loopback** — for capturing application audio during screen sharing (Windows only)

All permissions are used solely for their stated purpose and only when explicitly activated by the user.

## Changes to This Policy

Any changes to this privacy policy will be documented in this file and included in the project's release notes.
